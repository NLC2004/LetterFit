# 保研自荐邮件助手

从学院官网师资页整理老师名单，用大模型按对方研究方向改自荐信，**你确认后**再通过自己的邮箱发出。

- **隐私安全**：邮箱密码、名单、草稿全部只保存在你自己的电脑上，开源可查证
- **不编造**：你的经历、奖项保持原文，大模型只填与老师相关的四个空位（称呼 / 老师方向 / 交叉经历 / 契合段）
- **防滥用**：没有「一键全院群发」，封与封之间有间隔；每日上限见 `config/settings.yaml`

## 快速上手（约 3 分钟）

1. 安装 [Python 3.10+](https://www.python.org/downloads/)（安装时勾选 Add to PATH）
2. 双击 `启动.bat`（首次运行会自动建环境、装依赖，稍等片刻）
3. 浏览器会自动打开并进入**配置向导**，按提示完成 4 步。之后也可随时在「材料与配置」页直接填写：
   1. **个人信息**：姓名、学校、邮箱，以及你的科研/项目经历（大模型只从这里挑与老师的契合点）
   2. **发信邮箱**：下拉选择邮箱服务商 → 填写邮箱地址和邮箱密码 → 保存并测试登录（写入本机 `.env`）
   3. **大模型**：推荐 DeepSeek（新用户有免费额度），注册后粘贴 API Key → 保存并测试调用（写入本机 `.env`）
   4. **简历**：上传 PDF 作为附件；也可点「根据简历生成底稿」，让大模型按简历写一封带四个空位的自荐信，检查后保存
4. 向导完成后即可使用：
   - **师资名单**：粘贴学院师资页文本（或预填 `config/schools.yaml` 后一键抓取）→ 核对邮箱 → 勾选老师
   - **生成草稿**：为勾选的老师逐封生成个性化信件
   - **确认发送**：逐封预览、确认后发出

## 日常使用

```powershell
python -m streamlit run app.py
```

或直接双击 `启动.bat`。命令行也可用：`python cli.py fetch` / `draft` / `send` / `status`。

## 常见问题

**发信要填的密码是什么？**
就是你的邮箱密码。选好服务商后按页面说明填写；若学校要求先开启 SMTP，按学校邮件帮助操作即可。不要把填好的 `.env` 发给别人。

**学院网站打不开 / 抓不到？**
正常现象，很多学院网站会拦截程序访问。在「师资名单」页把浏览器里的师资页全文复制粘贴进去即可解析。

**老师没有邮箱怎么办？**
勾选后点「补全已勾选老师的主页信息」，程序会尝试从老师个人主页找邮箱（单次有上限）。

**一天能发多少？**
默认每天最多 10000 封（`config/settings.yaml` 的 `max_per_day` 可调），批量发送每封间隔 60 秒。短时间大量发送仍可能触发邮箱风控。

**程序出问题了怎么反馈？**
「材料与配置」页底部有「导出日志」按钮，把 `app.log` 发给作者即可。日志只记录操作和报错，不含邮件正文。

## 进阶：手动配置

所有配置也可以在文件里直接改：

| 文件 | 内容 |
|---|---|
| `.env` | 大模型 API Key、邮箱密码（**不要发给任何人**） |
| `config/profile.yaml` | 个人信息与经历（已被 gitignore，不会进仓库） |
| `Template/template` | 邮件底稿，保留四个花括号空位 |
| `config/schools.yaml` | 各学院师资页 URL |
| `config/settings.yaml` | 抓取与发送参数 |
