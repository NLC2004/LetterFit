# LetterFit — 保研自荐邮件助手

给真正相关的老师，写真正个性化的信。

从学院官网师资页整理老师名单，用大模型按对方研究方向修改你的自荐信，**你确认后**再通过自己的邮箱发出。你的邮箱密码、名单、草稿全部只保存在本地，代码开源可查证。

## 为什么用它

- **隐私安全**：邮箱密码、API Key、老师名单、草稿全部只保存在你自己的电脑上，开源可查证
- **不编造**：你的科研经历、奖项保持原文，大模型只填与老师相关的四个空位（称呼 / 老师方向 / 交叉经历 / 契合段）
- **防滥用**：没有「一键全院群发」，封与封之间有间隔，保护你的邮箱不被风控
- **小白友好**：首次启动配置向导，不需要改配置文件；支持根据简历自动生成邮件底稿

## 快速上手（约 3 分钟）

1. 安装 [Python 3.10+](https://www.python.org/downloads/)（安装时勾选 Add to PATH）
2. 双击 `启动.bat`（首次运行会自动建环境、装依赖，稍等片刻）
3. 浏览器自动打开并进入**配置向导**，按提示完成 4 步：
   - **个人信息**：姓名、学校、邮箱，以及你的科研/项目经历
   - **发信邮箱**：下拉选择邮箱服务商 → 填写邮箱地址和密码 → 测试登录
   - **大模型**：推荐 DeepSeek（新用户有免费额度），注册后粘贴 API Key → 测试调用
   - **简历**：上传 PDF 作为附件；也可点「根据简历生成底稿」，让大模型按简历写一封带四个空位的自荐信
4. 向导完成后即可使用：
   - **师资名单**：粘贴学院师资页文本（或预填 `config/schools.yaml` 后一键抓取）→ 核对邮箱 → 勾选老师
   - **生成草稿**：为勾选的老师逐封生成个性化信件
   - **确认发送**：逐封预览、确认后发出
